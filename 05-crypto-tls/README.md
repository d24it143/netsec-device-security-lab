# 05 - Cryptography and TLS

## Goal
Understand and demonstrate hashing, symmetric/asymmetric crypto, signatures and the TLS handshake.

## Tasks
- [ ] Hash a file and show the avalanche effect (change one character)
- [ ] AES encrypt/decrypt a file with OpenSSL
- [ ] Generate an RSA key pair, sign and verify a file
- [ ] Capture a TLS handshake in Wireshark; label ClientHello, ServerHello, Certificate, key exchange, Finished
- [ ] Inspect a certificate chain with `openssl s_client`
- [ ] Run `nmap --script ssl-enum-ciphers` and explain the output
